## 说明

本项目是学习辅助材料，不替代原书，也不构成心理、精神或医疗诊断与治疗建议。总结中尽量区分作者在原书中的主张与分析性提炼。严重或持续的心理困扰应寻求合格专业人士帮助。
## 新增：普通人的真实求助现场

23章均已加入来自本地 `ques_ans1.json` 数据集的匿名用户自述案例，共25个唯一案例；第10章与第16章各含两个案例。每个案例均区分提问者经历、社区回应与本书机制分析。社区回答不等同于临床诊断、专业意见或疗效证据，正文也未补写提问者未提供的后续结局。
